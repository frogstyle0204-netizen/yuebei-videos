# 卡点与音效

强节奏 = **镜头、字幕、音效、画面冲击全部落在拍点上**，再加两次「收暗 → 静止 → 爆发」。

## we-never 的网格（已实测，直接用）

```ts
export const BAR = (102.52 - 17.45) / 40;   // 2.12675 秒 / 小节，112.8 BPM
export const BAR0 = 17.45 - 8 * BAR;        // 0.436 秒
export const BEAT = BAR / 4;
export const beatSec = (b: number) => BAR0 + BEAT * b;
export const fbt = (b: number) => Math.round(beatSec(b) * 30);   // 第 b 拍的帧
export const fb = (k: number) => fbt(4 * k);                     // 第 k 小节的帧
```

| 位置 | 时间 | 用法 |
|---|---|---|
| 第 7 / 10 / 15 拍 | 4.19 / 5.79 / 8.46 秒 | 开场三次重音：死亡枪响、击杀回放、分屏 |
| 第 8 小节 | 17.45 秒（−19.6 → −2.0 dB） | 第一个爆点：标题卡 |
| 第 8、12、16 … 小节 | 每 4 小节 | 乐句起点：章节卡 |
| 每个乐句的第 3 小节 | 稍弱一档 | 适合放安静的结论句 |
| 第 40–47 小节 | 85.5–102.5 秒，整体回落约 2 dB，100–102.5 秒最低 | 「怎么办」；最后一句话说一半 + 收暗 |
| 第 48 小节 | 102.52 秒（−17 → −1 dB） | 第二个爆点：锚词 |
| 第 64 小节 | 136.55 秒 | 片尾（+1 秒淡出） |

两个重拍相隔正好 40 小节，所以用它们反推网格；beats.py 的「精修小节长」会强行凑整数小节，长片用它会漂。

### 换曲子时

1. `uv run --with numpy python .claude/skills/weilanx-creator-gilded-video/scripts/beats.py public/music/<曲>.mp3 --to 140` 找重拍候选。
2. 打每小节响度找乐句和回落段（把 `BAR`、`B0` 换成实测值）：
   ```python
   import subprocess, numpy as np
   SR=22050; x=np.frombuffer(subprocess.run(['ffmpeg','-v','error','-i','<曲>','-ac','1','-ar',str(SR),'-f','f32le','-'],capture_output=True).stdout,dtype=np.float32)
   r=lambda a,b: 20*np.log10(np.sqrt((x[int(a*SR):int(b*SR)]**2).mean())+1e-9)
   print(' '.join(f'{k}:{r(B0+k*BAR,B0+(k+1)*BAR):.0f}' for k in range(72)))
   ```
3. 第二个爆点找「连续 2 秒低谷后突然冲高」的地方，10 ms 精度确认（打印 ±1 秒的能量）。

## 收暗和静止

```ts
const dark = Math.pow(clamp01((f - DARK_FROM) / (HIT - FREEZE - DARK_FROM)), 0.7) * 0.94;  // HIT 前 ~0.75 秒起压到 94% 黑
const ff = f >= DARK_FROM && f < HIT ? Math.min(f, HIT - FREEZE) : f;                      // 最后 3 帧所有动画冻住
```

话说一半的字幕在 `DARK_FROM` 退场。第二个爆点同样处理（`DARK_FROM2 = fr(101.75)`）。

## 音效（`audio/sfx-tactical.mjs`）

| 音效 | 用在 | 音量 |
|---|---|---|
| `gunshot` | 死亡、命中、结尾爆头；演示里的连发 | 0.65–0.75（连发 0.5） |
| `crack` | 死亡红屏，枪响后 2 帧 | 0.55–0.7 |

| `impact` | 两个爆点、锚词第一次出现、大字结论 | 爆点 0.7，其他 0.45–0.5 |
| `chapter` | 章节卡（配 whoosh） | 0.5–0.6 |
| `tick` | 字幕逐句出现、方法卡亮起、毫秒条增长 | 0.4–0.55 |

ep25 一共 42 处。音效都是 −6 dBFS 峰值；配乐 −16 LUFS 时，冲击叠在配乐重拍上最容易顶到 0 dBFS，先压它。

## 测量

一键：`node .claude/skills/weilanx-creator-fps-video/scripts/qa.mjs <期> --audio`，报告整片响度、真峰值，并列出比前一刻高不到 4 dB 的冲击类音效（枪声、冲击、裂纹、章节、脚步）。下面是它背后的手动方法。


- 整片：`npx remotion render src/index.ts <期> /tmp/<期>/a.wav --codec=wav`，`ffmpeg -i a.wav -af ebur128=peak=true -f null -` → ep25 是 −15.5 LUFS、峰值 −1.5 dBFS。
- 交叉验证用 `volumedetect` 的 `max_volume`。**别自己把立体声 `-ac 1` 合成单声道再算峰值**，两路相加会多出 +2～3 dB 的假峰值。
- 音效存在感：音效点和前一段各取 0.25 秒比 `mean_volume`，高出 4 dB 以上才听得清（ep25：死亡枪响 +5 dB，两个爆点冲击 +8～9 dB）。
