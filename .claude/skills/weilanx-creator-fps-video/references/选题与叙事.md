# 选题与叙事

## 选题：冤 → 翻案 → 招

后台数据（`数据复盘.md`）说明：观众转发是为了替自己说话，所以好选题的核心是**有人被冤枉**。好选题同时满足四条：

1. **冤：标题是玩家骂过的话**，第二人称、痛点、问句，说的是他想不通的那一刻。「躲进掩体，为什么还被打死？」能点开，「跑着开枪为什么打不准」不行（答案大家早就知道）。不要「浅谈网络延迟」这种名词标题，也不要「连跳为什么越跳越快」这种不带「你」的机制问句。
2. **翻案：有一个能被「看见」的科学模型**，证明锅不在观众以为的地方（不是你菜，是网络 / 概率 / 大脑）。时间轴、俯视图、分布曲线、毫秒条、循环环……模型能在画面里演出来，观众是亲眼看到的。
3. **招：翻完案给一个马上能用的技巧**，放在「怎么办」那章，结尾在射击场里用它赢一次。技巧是加分项，不是选题本身。
4. **有一手资料撑住**：游戏官方技术博客、补丁说明、开源代码、论文。没有原文的题先不做。

## 锚词

2～4 个字，一个词装下整期的原理，结尾能被重新定义。ep25 是「过去」：开头是「你看到的都是过去」（冷知识），第二个爆点「你死在他的过去」（扎心），结尾「你们只是活在不同的时间里」（释然）。

## 字幕写法

- 每句从拍点开始，大多一小节（约 2.1 秒）一句；三连镜头时可以按拍切。
- 中文不超过 24 字；关键词用 `【】`青（你 / 正确 / 主线）、`〖〗`红（失误 / 死亡）、`〔〕`橙（答案 / 高手），一句最多一处。
- 出处要说出来：「Riot 的工程师说得很直白：」「Riot 估算：」——观众信的是出处，不是我们。
- 数字写阿拉伯数字 + 单位（141 毫秒、128 tick、144 帧）；估算类加「约」。
- 大字卡（标题、结论、情绪翻转、评论问题）不走字幕，`CUES` 里写 `null` + 注释。
