# 封面、字幕稿、发布文案

## 3:4 封面（ucloud-image-gen 文生图）

对标的 FPS 科普封面都**没有真人**：写实暗色射击游戏场景 + 超大粗体标题 + 一个关键词变色 + 一行副标题。所以这里不用 `weilanx-xhs-cover-ucloud` 的人物原图，直接文生图：

```bash
python3 <ucloud-image-gen>/scripts/ucloud_image.py generate \
  --prompt-file /tmp/<期>-cover-prompt.txt -s 1152x1536 -q high \
  -o <素材目录>/ --name <期>-cover-3x4
```

生成后 Read 看一眼，确认：标题无错字缺字乱码、没有游戏官方 logo / 角色、关键冲突（命中火花、敌人）清楚；满意就复制成 `<素材目录>/封面-3x4.png`。不满意就改 Prompt 重出一张。

Prompt 模板（ep25 一次成功）：

```text
生成一张严格 3:4 竖版的游戏科普视频封面（小红书 / 抖音竖版封面），主题是 FPS 战术射击游戏里的[原理]：「[挫败感标题]」。

画面风格：电影感写实的 3D 游戏截图质感，[夜晚雨后的战术射击地图]，深蓝黑色调，湿润地面反光，少量青色和红色的灯光点缀，中低明度，体积光和薄雾。像一张高质量游戏宣传截图，不是插画、不是卡通。

画面内容（下半部分 55%）：
- 主角：[一名穿深色战术装备的玩家（只看到侧后方背影，看不清脸），正在做什么]。
- 关键冲突：[挫败的那一刻，比如他已经躲好、肩膀上却炸开命中火花，一道细细的红色弹道从远处射来]。
- 远处背景：[模糊的红色敌人剪影，举枪瞄准，淡红色描边光]。
- 叠加在场景上的极简 HUD 示意线（细线、低调）：[一两个小标签，内容必须和片中数字一致]，以及画面中央一个青色十字准星。

标题（上半部分 40%，第一视觉中心，左右撑满）：
- 最上方一行小字：「FPS 原理课 · EP.[xx]」，青色等宽字体，小号，带一个小青色菱形。
- 第1行：「[前半句]」纯白色，特大号。
- 第2行：「[后半句普通词]」纯白色·大，紧接着「[关键词]？」鲜红色 #FF3B4E·特大号。
- 第3行（副标题，中号）：「[锚词那句]」亮青色 #3FD3F0。
标题字体：粗壮方正的黑体（类似思源黑体 Heavy / 方正综艺体），笔画饱满、字距紧；每个字有深色粗描边和向右下的黑色硬投影，白字带极轻微的冷色外发光，红字带轻微红色外发光。行距紧凑，整块标题像一块字牌。所有中文必须准确、清晰、完整，不能有错字、缺字或多余文字。

构图层级：标题第一、[关键冲突]第二、HUD 标签第三。四角有少量深色场景细节，不留大面积空白，标题周围保持干净。

严格避免：任何真实游戏的 logo、角色、官方枪械外观和商标（尤其不要出现 VALORANT / 无畏契约 的标志或英雄角色）；额外的英文大字；水印；卡通风格；浅色背景；人物正脸；错字和乱码文字。
```

## 字幕稿

```bash
node .claude/skills/weilanx-creator-fps-video/scripts/subtitle-doc.mjs src/episodes/<期>/timeline.ts <素材目录>/字幕稿.md
```

`CUES` 里 `null` 的条目用同一行 `// 注释` 当说明（如 `【标题卡】`）；话说一半的两句结束时间取收暗帧。

## 发布文案（`<素材目录>/发布文案.md`）

照 ep25 的结构：

```markdown
# <期> 发布文案

## 标题
[和封面一致的痛点问句，第二人称，说被冤枉的那一刻]（与封面一致；痛点提问式，N 字）

## 备选标题
- [公式 #14 [不想要的结果]的最根本原因]
- [公式 #12 看完这个，你的[想法]会不再相同]
（标题公式来自 dbs-xhs-title；小红书标题 ≤ 20 字含标点，留悬念不说答案）

## 描述
[开场重演那段挫败，2–3 句]

两分钟讲清楚「…」：
· [每章一条知识点，带一手资料的数字]

能做什么：
① … ② … ③ … ④ …

[情绪翻转那句]
[评论区问题]？评论区说说。

数据来源：[一手资料全名 + 年份]。画面、动画和字幕全部用代码一帧一帧画出来。

## 话题
#无畏契约 #瓦罗兰特 #FPS #游戏科普 #[本期原理] #打瓦 #电竞 #CS2 #知识视频 #Vibe知识大赏

## 发布前核对（内部，不要发出去）
- 片中每个数字的出处和测试位置
- 封面上的示意标签对应片中哪一档数字
- 封面由 ucloud-image-gen 生成，没有使用游戏官方素材
- 配乐授权状态
```

封面、字幕稿、发布文案都复制到 `<成片目录>/`；以后重新 `npm run export -- <期>` 时 `export.sh` 会自动从 `<素材目录>/` 带上。
