# 配乐卡点与音效

## we-never 网格（统一配乐，已授权 2026-10-11）

```ts
export const BAR = (102.52 - 17.45) / 40;   // 两个重拍相隔正好 40 小节，一小节约 2.127 秒
export const BAR0 = 17.45 - 8 * BAR;          // 第 0 拍 ≈ 0.44 秒
export const BEAT = BAR / 4;
export const fbt = (b: number) => fr(BAR0 + BEAT * b);   // 第 b 拍的帧
export const fb = (k: number) => fbt(4 * k);              // 第 k 小节
HIT = fb(8)        // 17.45 秒，第 32 拍
HIT2 = fb(48)      // 102.52 秒，第 192 拍（配乐换气后整段重新进来）
DARK_FROM = fr(16.7); DARK_FROM2 = fr(101.75); FREEZE = 3
DURATION = fr(beatSec(256) + 1)   // ≈ 137.5 秒
```

## 重拍前后

- 重拍前约 0.75 秒（`DARK_FROM`）起整体收暗到 94% 黑（`pow(…, 0.7)`），最后 3 帧画面静止（`ff = min(f, HIT − FREEZE)`）。
- 重拍帧：标题 / 锚词 **+2 帧必须已经亮**（`SparkTitle instant`、`GlowSmash`）。
- 每小节第一拍整屏轻推 1.2%，两个重拍 4%（`barPunch`，从 `src/library/lamplight/scenes` 引；字幕在推的那层外面）。

## 音效（`audio/episodes/<期>.mjs`，照 ep36）

`cutMusic({track: 'we-never', start: 0, duration: DURATION, ep, fadeIn: 0.02, fadeOut: 2})` 成功后 `makeTacticalSfx(EP)`（借 riser），再用 ffmpeg `aevalsrc` 合成本期的：

| 名字 | 用途 | 音量 |
|---|---|---|
| room | 极轻粉噪底噪，整片 | 0.5 |
| impact | 两个爆点、关键结论（第 8、32、120、152、192、216 拍） | 爆点 0.66–0.7，其余 0.4–0.45 |
| riser | 两个爆点前 2 秒 | 0.55–0.6 |
| chime | 数字亮起、天平落定、结论（落在强拍上） | 0.35–0.45 |
| **本期动作音** | 模型里的动作，卡开场四连和回落段硬拍。ep36：press 拉杆咔哒（0.5–0.7）、drop 食粒落槽碎响（0.45–0.6）、run 小碎步（0.6） | — |
| 共享 whoosh / paper | 换章、引文出现 | 0.22–0.3 |

动作音按选题设计：拍卖 → 木槌 / 硬币；旁观者 → 心跳 / 呼救声的抽象音（不要真人声）；天平 → 金属轻碰。合成后 `alimiter=limit=0.5` 压峰。

## 响度自查

- 整片约 −15.5 LUFS（ep36 −15.4）、真峰值 ≤ −1 dBFS（ep36 −1.7）。超了找峰值所在 0.1 秒窗口，通常是 impact + 动作音 + 配乐重音叠在同一拍，压低或去掉 impact。
- 高频小音效（铃、碎响、咔哒）用 1.2–5 kHz 带通比前后能量，要高出 10 dB 以上；全频 RMS 会被配乐重音淹掉、量不准：
  ```sh
  ffmpeg -nostats -ss <秒> -t 0.2 -i a.wav -af "highpass=f=1200,lowpass=f=5000,volumedetect" -f null - 2>&1 | grep mean_volume
  ```
- **听不到声音要如实说**，只报数字。
