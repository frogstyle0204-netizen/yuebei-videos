## 每期都要有的「出彩设计」（3～5 个，只属于这个选题）

用户 2026-10-13 明确要求：不要只拼素材包，要为选题设计体验感。套路（详见配方卡「出彩的手法」）：

1. **一个舞台贯穿全片**：开场、回落段、结尾回到同一个小世界，推导段只是离开一会儿。
2. **角色有生命**：呼吸、眨眼、甩汗、打呼、吃东西掉碎屑——先让观众对角色有情绪。
3. **把推理变成实物**：比较 → 天平；减法 → 东西飞走；累计 → 对账卡；陷阱 → 红烟 + 灯闪。
4. **硬拍推动数字**：回落段每一下硬拍都改变一个数，让观众亲眼看到结论成立。
5. **连续长镜头转场**：推理收尾时镜头推进结论那一格（ep36：`transform-origin` 设在纳什均衡格中心、最后 20 帧放大 6 倍淡出），下一镜头从 1.25 倍落回 1 倍。
6. **反面情况要有感官**：0 : 0 时灯接触不良（`flicker`）、肚子「咕……」。

做完把通用的挪进 `src/library/blackgold/`（`pen.tsx` 就是 ep36 沉淀出来的），补 `src/library/README.md` 和配方卡。

## 版式

- 字幕区 y > 880 留给字幕；舞台地面 `FLOOR_Y = 800`，舞台元素别压进字幕区。
- 顶部 0–200 给 `ChapterTag` / `CiteLine` / `Ledger`；有对账卡时把舞台整体 `translateY(40) scale(0.94)`（原点底部中间）让出顶部。
- 收益矩阵靠左（x ≈ 400），右边留给天平（cx ≈ 1500）；均衡标签在矩阵右侧，天平在标签出现前淡出。
- 两个角色挨着时，大的放后面、小的画在前面，脚底中心至少隔开两者半宽之和（ep36 初版大猪压住小猪）。

## ep36 踩过的坑

- 标题在重拍 +2 帧还没亮 → `SparkTitle` 加 `instant`。
- `TickRing` 半径太小压住术语小字 → r ≥ 400。
- 天平数字压在吊绳上 → 数字放秤盘里（`top: ey + 62`）。
- 对账卡、食粒在 0.4 倍缩略图里太小 → 对账卡数字 54 / 76px、食粒 58px。
- Root 里有风格 `<Folder>`，新一期要注册进 `09-黑金光影风`，不要跟在别的风格最后一期后面。

## 自查清单（看 `qa.mjs` 拼图时逐条过）

- 文字重叠、出画、折行（标题、卡片、天平标签、对账卡）；舞台元素压进字幕区
- 该出现的东西都出现了（每个元素的出场帧在镜头范围内）；角色互相遮挡
- 爆点：−16 已开始收暗、−3 静止、+2 标题 / 锚词已经亮
- 中段抽帧：角色在跑、天平在晃、数字在跳，动画不是静止的
- 示意画面有「示意」标注；出处行写对作者、年份、卷页
- 响度约 −15.5 LUFS、峰值 ≤ −1 dBFS
