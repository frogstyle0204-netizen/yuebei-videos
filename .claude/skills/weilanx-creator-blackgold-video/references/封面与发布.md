# 封面、发布文案、字幕稿

## 3:4 封面（代码渲染）

不用 AI 生图：中文一个字都不会错，画风和片子一致。照 `src/episodes/ep36-boxed-pigs/CoverTall.tsx`（1080×1440 的 `Still`）：

- **上半标题字牌**：系列小字「黑金光影 · <领域>」（36px，灰，字距 12）→ 金色大标题（宋体 Black 176px，`#ffe9b0` + 多层金色光晕，和 `SparkTitle` 一致）→ 米白问句副题（92px，两行，关键词用青色发光）→ 红框钩子条（52px，一句戳痛点的话，不换行）。
- **下半主视觉**：把片中的舞台放进 `Stage`（1920×1080 舞台用 `left` / `top` / `scale` 裁进竖版），取最有戏的一刻（ep36：大猪甩汗奔跑 + 小猪趴着打呼）。动画帧取一个好看的固定值（`T = 47`）。
- **压暗层**：上半渐变压暗；底部一条压暗带。
- **底部一行结论数字**：灰色说明 + Garamond 大号金字（ep36「跑断腿 vs 躺着，净得 4 : 4」），必须和片中某句一致。
- 在 `src/Root.tsx` 的 `09-黑金光影风` 文件夹里注册 `<Still id="<期>-cover-tall" …>`。

```sh
npx remotion still src/index.ts <期>-cover-tall <素材目录>/封面-3x4.png --timeout=120000 --log=error
```

渲完 Read 看：标题无压字、钩子条不换行、主视觉不被标题挡住、底部数字不压角色。

## 字幕稿 + SRT

```sh
node .claude/skills/weilanx-creator-blackgold-video/scripts/subtitles.mjs <期> <素材目录>
```

产出 `字幕稿.md`（序号 | 时间 | 中文 | English）和 `字幕.srt`（双语两行）。标题卡、锚词爆点自动写成「标题：副题」「锚词（术语）」。

## 发布文案（`<素材目录>/发布文案.md`，结构照 ep36）

```markdown
# <期> 发布文案

## 标题
[和封面一致的悬念问句]（与封面一致；悬念提问式，N 字）

## 备选标题
- [反常识提问，钩子落在观众的处境]
- [结果先行，答案留到片里]

## 描述
[开场白描，2 句]

两分钟讲清楚「<模型名>」：
· [出处：年份 + 谁 + 做了什么 + 原文结论]
· [规则和数字]
· [推导两三步，带术语]

[结论那句 + 反面情况]
[重新定义锚词那两句]

[评论区问题]？评论区说说。

资料来源：[作者, 题目, 期刊 卷:页 (年份)；书名 + 章节表号]。画面、动画和字幕全部用代码一帧一帧画出来，[舞台]为示意。

## 话题
#<模型名> #博弈论 / #经济学 / #心理学 … #冷知识 #知识视频 #涨知识 #Vibe知识大赏

---

## 发布前核对（内部，不要发出去）
- 每个数字的出处、核对情况（原文 / 摘要 / 自己算 / 示意）、测试位置
- 原实验和课本说法的差异；有意没说的
- 标题和事实的口径（会被挑刺的地方怎么回复）
- 封面数字对应片中哪一句
- 配乐：we-never，用户确认已授权（2026-10-11）
- 片尾没有下期预告
```

封面、发布文案、字幕稿、字幕.srt 都复制到 `<成片目录>/`。
