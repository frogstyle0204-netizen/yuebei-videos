# 叙事与字幕

没有口播，字幕就是旁白。观众只靠读字和看画面理解，所以每一句都要短、要有画面、要在对的拍子上出现。

## 锚词：先找它，再写别的

锚词是全片的钉子：2～4 个字，是这个知识落在普通人生活里的**处境、困惑或反直觉的瞬间**，不是术语本身。

三个标准：

1. **代入感**：观众一看就觉得「这说的就是我」。
2. **概括力**：同一个词能装下整个原理。
3. **可重定义**：开头它是困境或不在乎，结尾它变成理解、释然或力量。

例子：

| 知识 | 锚词 | 开头的意思 | 结尾的意思 |
|---|---|---|---|
| 指数增长（ep23） | 一点点 | 每天只多一点点，没什么用 | 一点点，从来不只是一点点 |
| 红皇后效应 | 原地 | 拼命跑，却还在原地 | 原地，是因为大家都在跑 |
| 沉没成本 | 舍不得 | 舍不得已经花掉的 | 舍得，才走得出去 |
| 幸存者偏差 | 看不见的人 | 只看到成功的人 | 真正的答案在看不见的人那里 |
| 局部最优解 | 下山 | 站在小山头不想下来 | 想登更高的山，你得先下山 |

找不到好锚词时，先写下「这个原理让普通人吃过什么亏 / 有过什么困惑」，从里面挑一个能说出口的词。

## 结构（以 ep23 为例，按小节写）

| 段落 | 小节 | 写什么 |
|---|---|---|
| 钩子第一句 | 0 | 第二人称写观众的悖论：「你每天只多做一点点，」 |
| 钩子第二句 | 2 | 把悖论问出来：「为什么总觉得，什么都没变？」 |
| 展开 | 4、6 | 让现象一点点出现，可以借一个故事 / 传说 / 实验，但不讲术语 |
| 话说一半 | 重拍前一小节 | 以「——」结尾：「国王笑了：每格不过多那么——」 |
| **重拍** | 第一个重拍 | 锚词大字砸出来补完上一句；0.6 秒后浮出「术语 · English」 |
| 原理 | 重拍后 | 这时才讲数字、人物、原理；每句一个信息点 |
| 第二个爆点（可选） | 某个小节线 | 同样「话说一半 → 大字补完」：「放到秤上，它相当于全世界——」→「一千多年的小麦」 |
| 重定义 | 倒数第二句 | 锚词再出现，意思翻过来：「一点点，从来不只是一点点。」 |
| 抛问题 | 最后一句 | 和观众有关、每个人都有自己答案：「你身边，有什么正在悄悄翻倍？」 |

钩子段的另一种写法：3～4 个快速画面，让同一个现象在不同尺度上各出现一次（个人 → 自然 → 社会），再用「所以，……」收到同一个悖论上。片长够时用这种，信息更密。

## 抛问题：决定评论区

复盘里，抛问题那条评论 397 条，没抛的只有 8 条和 11 条。好问题的特点：

- 跟观众自己有关（「你身边」「你会怎么选」）。
- 没有标准答案，每个人都有自己的答案，觉得是和觉得不是的人都想说两句（「安稳算不算人生的最优解？」）。
- 只让人「有感触」的结尾（迷茫、走散）没人开口，要把感触变成一个能回答的问题。

## 字幕的写法

- 每屏一句中文，下面一行英文斜体（`GCaption` 的 `en`）。英文是意译，要读起来像一句话，不逐字对。
- 中文不超过 18 字，要短、有画面、有一点诗意；可以用破折号制造停顿，不用冒号括号堆信息。
- 每句从小节线开始，停 1～2 个小节（约 2～4 秒）；全片句数 ≈ 片长秒数 ÷ 3。
- 重点词用 `【】` 包起来变金色，一句最多一处。
- 数字写成阿拉伯数字加千分位（1,023、1,844 亿亿）；大数用中文量级（亿亿）让人能读出来。

## 核对

- 片中每个年份、人名、数字、引文、「第一次」「最」这类说法都要查实；查不实的不放。
- 用代码算得出的数字（倍数、合计、比例）写进 `timeline.ts` 的函数，测试里断言。
- 估算类数字在画面上用小字写清口径。
- 交付时在回复里列出所有需要用户发布前再核对的点。
