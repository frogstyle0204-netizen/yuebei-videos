# 配乐与卡点

纯音乐短片的情绪曲线就是配乐的曲线。先测音乐，再排字幕和画面。

## 音乐库

- 曲子放 `public/music/`（音频不进 git），目录和授权记在 `public/music/README.md`，代码里的曲目表是 `audio/music.mjs` 的 `TRACKS`。
- 截取并处理成某一期的配乐：
  ```js
  // audio/episodes/<期>.mjs
  import {cutMusic} from '../music.mjs';
  cutMusic({track: 'we-never', start: 0, duration: 33.5, ep: '<期>', fadeIn: 0.02, fadeOut: 2});
  ```
  `lufs` 默认 −16（无口播，配乐是主音轨）。从第 0 秒开始放，片长跟着音乐的段落走，结尾 2 秒淡出。
- **配乐要从第 0 秒开始用**，不要截中段：曲子的第一个「换气 + 重拍」通常在开头 15～20 秒，正好是钩子段的长度。

## 实测卡点

```sh
uv run --with numpy python .claude/skills/weilanx-creator-gilded-video/scripts/beats.py public/music/<曲子>.mp3 --to 40
```

输出怎么用：

- **推荐高潮**：得分最高的候选（前面有一段持续回落的「换气」+ 最大的冲高）。这就是 `HIT`。
- **精修小节长**：起音到重拍之间是整数个小节，脚本用这个反推出精确小节长。`BAR0` 取起音，`BAR` 取精修值；检查 `barSec(n)` 和重拍相差不到 1 帧。
- 自相关给的 BPM 可能锁到半速或 1.5 倍：结果明显不对（比如慢歌给出 150）时，用 `--bpm 60 100` 这类范围重跑。
- 不放心时，在重拍前后 1 秒按 10ms 打印能量曲线看一眼：换气是一段持续下降，不是一帧的小坑。

we-never 的实测：起音 0.36 秒，一小节 2.136 秒（≈112 BPM），第一个重拍 17.45 秒（第 8 小节），能量从 16.4 秒开始回落、17.43 秒约 −19 dB、17.47 秒冲到约 −2 dB。第二个可用的强拍落在第 12 小节（25.99 秒）附近。

## 对位规则

- 字幕切换、画面节点、音效都卡小节线（`barSec(k)`），不要随便切。
- `HIT` 与实测重拍误差不超过 2 帧（测试里断言）。
- 换了歌：重跑脚本 → 改 `BAR0` / `BAR` / `HIT` / `DARK_FROM` → 字幕按小节号写的会自动跟着走。

## 音效

只加少量，轻、短、干净，不抢音乐：

| 位置 | 音效 | 音量 |
|---|---|---|
| 第一个重拍 | 本期生成的低沉冲击 `impact.wav` | 0.9 |
| 第二个爆点 | 同一个冲击 | 0.55 |
| 关键转场 | `sfx/paper.wav`、`sfx/whoosh.wav` | 0.18～0.25 |
| 锚词重定义 | `sfx/magic.wav` | 0.2 |
| 片尾问题出现 | `sfx/ding.wav` | 0.22 |
| 全片 | 本期生成的底噪 `room.wav`（粉噪声过滤，约 −44 LUFS） | 1.4 |

冲击音效和底噪照 `audio/episodes/ep23-wheat-chessboard.mjs` 用 ffmpeg 生成：下滑低频正弦（70→35 Hz）+ 低通褐噪声，指数衰减 1.6 秒，**峰值压到约 −6 dBFS**（满幅的冲击叠在 −16 LUFS 的配乐上会削波，无口播的期数导出时不会走分轨重混）。

## 交付前检查

- `ffmpeg -i <成片目录>/<期>.mp4 -af ebur128=peak=true -f null -` 看整片响度（约 −16 LUFS）和峰值（不高于 −1 dBFS）。
- 听感只能用户确认：回复里如实说明「只看了数值，没有听」。
