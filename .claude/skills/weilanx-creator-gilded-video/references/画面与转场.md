# 画面与转场

风格配方见 `styles/我的风格/暗金文献风/README.md`，组件目录见 `src/library/README.md`「暗金文献风 gilded/」。这里只写做一期时的手法和 ep23 里验证过的实现。

## 底层固定三件

```tsx
<GildedBg f={f} glow={[50, 44]} />   // 近黑底 + 暖光晕 + 暗角（安静段落可 tone="cool"）
<Dust f={f} />                        // 漂移的金色浮尘
...画面...
<Grain />                             // 最上层胶片颗粒
```

配色只用四类：黑底、金（线条、数字、重点词）、象牙白（正文、实物）、一种朱红（强调的那一条路径、劣势一方、印章）。一个画面里最多一处朱红。

## 第一秒：视觉锚点

复盘结论：火的视频第一秒都有一个「让眼睛落脚的点」。只有一根线慢慢画、或者空画面淡入，开头就留不住人。

- ep23：第一帧镜头放大 7 倍对准棋盘第一格，一粒发光的麦子在画面中央，周围一圈呼吸的光晕（光晕要跟着麦粒在屏幕上的位置走，镜头拉远时别留在原地）。
- 换题材时找对应物：一枚硬币、一个红点、一根火柴、一颗星。小、亮、在中央、会呼吸。

## 镜头：一个世界里推拉

把一段内容放在同一个「世界坐标」里，用 `translate + scale` 做镜头：

```tsx
const tx = 960 - focus.x * scale;
const ty = 450 - focus.y * scale;
<div style={{transformOrigin: '0 0', transform: `translate(${tx}px, ${ty}px) scale(${scale})`}}>…世界…</div>
```

`focus` 从细节插值到整体、`scale` 从大到小，就是一个从细节拉远的长镜头。缓动用 `easeInOut`，一次推拉 2～4 个小节。

## 转场：同一个元素贯穿前后

优先级从高到低：

1. **同一个元素变形**：麦粒拉远成棋盘（ep23 开场）；大字缩小成一粒麦子（ep23 结尾）；圆缩成太阳 / 烛火；线延伸成地平线。
2. **同一画面里让位**：棋盘缩到左边、右边画出曲线（ep23 第 10 小节）。眼睛不用重新找重点。
3. **推近到一个细节，细节铺满后展开成下一场。**
4. 实在接不上时才用模糊交叉淡化（`vis(f, a, b)` 两头各 12 帧），前后画面不要长时间叠在一起。

## 重拍那一帧（ep23 的 `Smash`）

```
DARK_FROM（重拍前 ~0.7 秒） 画面整体压暗，按 pow(p, 0.7) 收到 94% 黑；话说一半的字幕同时退场
HIT − 3 帧                  所有元素静止（相机用 min(f, HIT − FREEZE) 算）
HIT                         压暗瞬间放开；中心光晕骤亮后 26 帧内回落；
                            锚词金色大字（约占画宽 1/3，字号 ~220）从 1.12 倍在 8 帧内收到 1 倍，之后极轻微呼吸；
                            一圈光环从字背后（半径 ≈ 字号 × 1.6）在 40 帧内扩到 1300 并淡出，内圈细环跟随
HIT + 18 帧（0.6 秒）       下方柔入「术语 · English」
HIT 起 2 小节               保持，只有呼吸；然后淡出进入讲原理的段落
```

第二个爆点用同一个 `Smash`，字号、光环、光晕都小一号（ep23：字号 130、光环 700、光晕 0.6），再配一枚 `RedStamp`。全片最多两次。

## 讲原理的画面

用素材库现成的金线图表，线要「画出来」（`pathLength={1}` + `strokeDasharray={`${p} 1`}`）：

| 想表达 | 组件 / 做法 |
|---|---|
| 翻倍、指数 | 棋盘逐格点亮（ep23 `Chessboard`，前几格真画出麦粒，后面写 2ⁿ）、指数曲线（最后一段描朱红） |
| 概率、分支 | `GoldTree`（高亮路径朱红）、`GaltonBoard`、`BellBars` |
| 收敛、大数 | `RatioChart` |
| 人群、样本 | `DotField` |
| 对比两个量 | 横向重量条（ep23 `WeightBar`）：小的那条只留一个亮点，大的拉满 |
| 循环、周期 | `GoldWheel` |
| 文献、记录 | `Parchment`、`BookCite` |

大数字用 `goldText` 渐变金，小字号重点用 `goldTextLight`。

## 自查清单

- 第一秒有没有一个亮的小东西在中央？
- 重拍前 6 帧：收暗 → 静止 → 爆发，是否踩在 `HIT` 上？
- 字幕（y≈950）有没有压到图表、棋盘或大字？
- 转场是不是至少有两处是「同一元素贯穿」？
- 一个画面里朱红是不是只有一处？
