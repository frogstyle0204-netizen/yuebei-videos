# 封面、发布文案、字幕稿

## 3:4 封面（代码渲染）

不用 AI 生图：中文一个字都不会错，画风和片子完全一致。照 `src/episodes/ep28-express-relay/CoverTall.tsx`（1080×1440 的 `Still`）：

- **上半（0–620px）标题字牌**：系列小字「灯火史话 · 古代XX」（36px，灰，字距 12）→ 金色大标题（宋体 Black 150px，金色光晕；标题里的关键词加「」）→ 米白副标题（118px，问句）→ 朱红描边钩子条（54px，一句打破误会的话，如「一匹马，跑不完八百里」）。
- **下半主视觉**：把横屏组件放进 `Stage`（1920×1080 的舞台裁进竖版，`left` / `top` / `scale` 定位）——地形图 + 全部点亮的路线 / 城市方格，前景一个动作定格的主角（`Horse pose="leap"` 举火把）。
- **压暗层**：上半渐变压暗成夜空（叙述区干净），底部再压一点暗给右下角的数字。
- **右下角一个数字**：灰色小标签 + 宋体 Black 大字（金色关键词），对应片中最狠的那个数（「1791 年 · 六百里加急 / 6 天到兰州」）。
- 所有动画传「已落定」的帧（`F = 9999`）；火焰取一个好看的帧。

```sh
npx remotion still src/index.ts <期>-cover-tall <素材目录>/封面-3x4.png --timeout=120000 --log=error
```

渲完 Read 看一眼：标题无压字、钩子条不换行、主角姿势有动感、右下数字和片中一致。

## 字幕稿

```sh
python3 .claude/skills/weilanx-creator-lamplight-video/scripts/subtitle_doc.py src/episodes/<期>/timeline.ts <素材目录>/字幕稿.md
```

## 发布文案（`<素材目录>/发布文案.md`）

标题公式用 `dbs-xhs-title` 挑（标编号），≤ 20 字、留悬念不说答案。结构照 ep28：

```markdown
# <期> 发布文案

## 标题
[和封面一致的悬念问句]（与封面一致；悬念提问式，N 字）

## 备选标题
- [公式 #16 [行为]的后果]（钩子落在惩罚上）
- [公式 #14 [结果]的最根本原因]

## 描述
[开场的误会和翻转，2–3 句]

两分钟讲清楚「…」：
· [每个朝代 / 每章一条，带史料里的数字和原文]

[重新定义锚词的那两句]
[情绪翻转那句]

[评论区问题]？评论区说说。

资料来源：[书名 + 卷，逐个列；转引的写「据某某」]。画面、动画和字幕全部用代码一帧一帧画出来，地形和路线为示意。

## 话题
#[本期关键词] #古代XX #历史冷知识 #中国古代 #[朝代] #历史科普 #涨知识 #知识视频 #Vibe知识大赏

---

## 发布前核对（内部，不要发出去）
- 片中每个数字的出处（书 + 卷 + 条目）、核对情况（原文 / 转引 / 自己算的）、测试位置
- 有意没说的（俗称不当规定讲、版本差异）
- 封面是代码渲染的，封面上的数字对应片中哪一句
- 配乐授权状态（we-never：用户确认已授权，2026-10-11）
- 片尾预告的下期，换题要改片尾再导出
```

封面、字幕稿、发布文案都复制到 `<成片目录>/`；以后重新 `npm run export -- <期>` 时 `export.sh` 会自动从 `<素材目录>/` 带上。
