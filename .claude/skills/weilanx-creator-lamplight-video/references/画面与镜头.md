# 画面与镜头

风格配方：`styles/我的风格/灯火史话风/README.md`；组件目录：`src/library/README.md`「灯火史话风 lamplight/」；ep28 的本期件：`src/episodes/ep28-express-relay/scenes.tsx`（`NightRoad`、`MapView`、`FlowDots`、`darkness`）和 `Ep28Relay.tsx`（`panelAt`、`punch`、各镜头写法）。

## 内容 → 组件

| 想表达 | 用什么 | ep28 例子 |
|---|---|---|
| 一个人 / 一群人做某事 | `Figure`（站 / 举手 / 举火把 / 指向 / 喊话 / 躺，`walk`、`flip`、`color` 变灰）、`Crowd` 远景人群 | 驿站交接、让路的行人 |
| 赶路、狂奔 | `NightRoad`（里程桩往后流，`off` 传跑过的距离）+ `Horse`（`run` + `torch`）+ `HoofDust` + `Embers` | 开场驿马、「拿命赶路」 |
| 累死 / 倒下 | `Horse pose="fall"`（`fall` 0–1 跨两拍，颜色变灰）+ `GroundRing` 红圈 + `StatCorner strike` 划掉数字 | 第 7、8 拍 |
| 原文、律令 | `Scroll`（竖排列放不下会自动缩字号；`box` 朱红题签、`seal` 方印、`cite` 出处） | 《唐六典》《唐律》、赦书 |

| 某个区域禁行 / 可行 | `WardPlan`（`ban` 斜纹 + 四面「禁」、`walkers`） | （宵禁类题目） |
| 从 A 到 B | `MapView` 里 `GlowRoute`（`fire` 路头一团火，`color` 换红）+ `Waypoint`（城 / 点 / 火） | 范阳 → 长安 |
| 一站一站往前传 | `RelayChain`（`stops` 位置、`litAt` 每站点亮帧 = 砸点）+ 镜头 `keyframes` 跟着路头走 | 北京 → 兰州 11 站 |
| 逐级加码的惩罚 / 数字 | 几个 `StatCorner` 依次出现（`prefix` 杖 / 徒 / 第，`from` 接上一个、`out` 让位） | 杖 80 → 杖 90 → 徒 2 年 |
| 一个字砸下来 | `BigGlyph`（红 = 惩罚，金 = 锚词；`sub` 一行小字）+ 背景压暗 | 「绞」「奇迹」 |
| 几档对比 | `TierCards`（按 `at` 依次亮，各自 `color`） | 按程 / 300 里 / 600 里 |
| 比例、额度 | `HorseQuota`（n 匹里 dead 匹逐个倒下）、`TallyCard` 人数卡 | 十匹死七匹 |
| 信物、令牌 | `GoldPlaque`（朱漆金字、`gleam` 高光） | 金字牌 |
| 时间流逝 | `DayNightDial`（`p` 转一圈 = 一昼夜）、`DynastyAxis` 朝代轴、`Moon` | 昼夜盘、「第 N 天」 |
| 对话、疑问 | `SayBubble` 金边气泡 | 「怎么还没到……」 |
| 标题、下期 | `TitleCard`（`perChar` 0.7 让标题在重拍帧就亮） | 17.45 秒、片尾 |
| 情绪翻转、评论问题 | `Narration align="center"` 两行 + `BigGlyph` | 「它变成了一句话：八百里加急」 |

颜色含义：蓝 = 名词 / 制度，红 = 惩罚 / 死亡 / 极限，金 = 火 / 速度 / 数量 / 答案；一个画面里红色只给惩罚和极限。

## 叙述的分屏

`CUES` 第三项 `true` 表示另起一屏；主组件里用 `panelAt(ff)` 取当前这一屏（从最近的「另起一屏」到下一屏之前），整屏交给一个 `Narration`（`key` 用这屏第一句的拍号，换屏时重新入场），叙述层放在冲击层外面、收暗层下面。话说一半的屏传 `out={DARK_FROM}`。

## 地图镜头

- 地图坐标 2600×1600，`MapView cam={[x, y, s]}` 把地图点 (x, y) 放在画面中心；地点和路线写在 `timeline.ts` 的 `PLACES` / `wiggle()`，按真实方位大致摆（东北范阳、西北兰州），但地形是程序生成的，SourceNote 写「路线为示意」。
- `MapView` 自带左上压暗（`MapShade`），叙述压得住满地光点；路线和地名尽量放在画面中下、右侧。
- 镜头用 `keyframes(ff, [[帧, 值], …])` 推拉平移；回落段让镜头跟着路头走，终点进画面的时候正好是最后一个砸点。
- 看全国用 `s ≈ 0.74`（再小会看到地图边）；看一段路用 `s ≈ 1.0`。

## 镜头节奏

- **全部硬切**，切点在拍上（开场按拍、正文按小节）；转场特效只有爆点白闪、「绞」的压暗和抖动。
- 每个镜头 1～4 小节；`SHOTS` 首尾相接，主组件里 `inShot(f, SHOTS.x)` 分支渲染，同一画面跨两个镜头时写 `inShot(a) || inShot(b)`。
- 画面右下角：有出处的镜头放 `SourceNote`（底部居中），没有的放 `Disclaimer`「人物和场面都是示意」。

## ep28 踩过的坑（自查时逐条看）

1. **纸卷溢出**：竖排一列字太长会折到下一列、三个字的方印会折成两行 → `Scroll` 已自动缩字号；仍然太挤就把原文拆成两列。
2. **地名撞右上数字**：地图右上角的城（北京、范阳）和 `StatCorner` 撞车 → 地名换边（`side="left"` / `"bottom"`）、数字挪到右下（`y={760}`），或者镜头往下移。
3. **标题卡在重拍帧必须已经亮**：默认逐字会让 +2 帧只有一个字 → `perChar={0.7}`。锚词用 `BigGlyph`，+2 帧已经清楚。
4. **马的倒下要像倒下**：腿还伸着会像在跳 → `fall` 贴地、腿放平、头垂；摔下的人放到马身后，别叠在马身上。封面用 `pose="leap"` 腾空定格，`run` 的随机一帧常常像在走路。
5. **一排小马会挤**：`HorseQuota` 间距是 `360 × size`，`size` 别大于 0.45，起点 x ≈ 300。
6. **满地光点压字**：叙述放在地图上时一定要有 `MapShade`（`MapView` 已带）。
7. **相邻镜头里同一个东西的位置要接得上**：开场的路和「绞」那场的城用的是同一条 `ROUTE_ROAD`。
8. **示意别编数字**：地图路线、光点位置都写「示意」；画面上的每个数字都要在事实清单里有出处。
9. 不画真实人物肖像、不画任何作品里的角色；人一律是米白象形小人。
