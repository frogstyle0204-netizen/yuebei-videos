# 叙事与卡点

强节奏 = **叙述、镜头、音效、画面冲击全部落在拍点上**，再加两次「收暗 → 静止 → 爆发」，外加回落段一串「一拍一个动作」。

## we-never 网格和实测硬拍

```ts
export const BAR = (102.52 - 17.45) / 40;   // 2.12675 秒 / 小节，112.8 BPM
export const BAR0 = 17.45 - 8 * BAR;        // 0.436 秒
export const BEAT = BAR / 4;
export const beatSec = (b: number) => BAR0 + BEAT * b;
export const fbt = (b: number) => fr(beatSec(b));   // 第 b 拍的帧
export const fb = (k: number) => fbt(4 * k);        // 第 k 小节的帧
```

## 钩子（5 个，文案稿里单独列）

1. 0 秒反常识（误会 → 3 秒内打掉）
2. 17 秒悬念（话说一半）
3. 中段一句狠话 + 全屏砸字（惩罚、死亡）
4. 后段一个冷知识数字（额度、比例）
5. 102 秒锚词 + 结尾重新定义

## 叙述写法

- 每句从拍点开始；正文大多一小节一句，开场和回落段按拍。
- 每屏 2～4 句往下累加，换镜头时整屏换掉（`CUES` 第三项 `true` = 另起一屏）；地图镜头别超过 3 句，挡路线。
- 中文每句 ≤ 24 字（含数字、标点不含标记）；一句最多两处标记，三种颜色语义固定，别为了好看乱用。
- 出处要说出来：「唐朝把规矩写进了【唐六典】：」「史学家说，」——观众信的是出处。原文引用加中文引号，引号里的原文不改字。
- 数字用阿拉伯数字 + 单位（2520 里、6 天、953 座）；古文里的数字保留汉字（「一日杖八十」）。
- 大字卡（标题、锚词、「绞」、情绪翻转、评论问题、下期）不走叙述，`CUES` 写 `null` + `// 注释`。

## 收暗、静止、冲击

```ts
const darkness = (f, from, hit, freeze = 3) => (f >= hit || f < from ? 0 : Math.pow(clamp01((f - from) / (hit - freeze - from)), 0.7) * 0.94);
const ff = f >= DARK_FROM && f < HIT ? Math.min(f, HIT - FREEZE) : f >= DARK_FROM2 && f < HIT2 ? Math.min(f, HIT2 - FREEZE) : f; // 最后 3 帧动画冻住
// 小节冲击：每小节第一拍放大 1.2%、7 帧回落；两个爆点 4%、10 帧；回落段（40–47 小节）减半；叙述层放在冲击层外面
```

话说一半的叙述在 `DARK_FROM` / `DARK_FROM2` 随收暗模糊退场（`Narration` 的 `out`）。爆点那一帧加 `Flash`。

## 音效（ep28 实际用量，约 60 处）

| 音效 | 用在 | 音量 |
|---|---|---|
| `impact`（战术屏包） | 开场数字砸出、两个爆点、全屏砸字、大字卡 | 爆点 0.66–0.7，砸字 0.62，其他 0.4–0.55 |
| `riser`（战术屏包） | 两个爆点前 2 秒 | 0.6–0.65 |
| `hoof` 马蹄 | 开场每拍一下（第 0–6 拍）、驿马出发、回落段每个砸点 | 0.3–0.6 |
| `drum` 大鼓 | 踉跄、换章、逐级加码 | 0.4–0.6 |
| `ignite` 点火 | 路线 / 火点亮 | 0.5 |
| `bell` 驿铃 | 驿站亮起（开场三连、回落段每个砸点）、关键数字 | 0.35–0.6 |
| `tick`（战术屏包） | 电报这类「现代」的东西 | 0.5 |
| 共享 `paper` / `stamp` / `whoosh` | 纸卷展开 / 律文落定 / 换场 | 0.35–0.7 |

**峰值的坑**：回落段砸点本身就 −2 dB 左右，「冲击 + 铃 + 蹄」再叠上去会到 −0.5 dBFS。ep28 的处理：最后一下（兰州）不加冲击、铃压到 0.5，「绞」的冲击压到 0.62，爆点 2 压到 0.66 → 整片 −15.2 LUFS、峰值 −1.8 dBFS。驿铃是高频，用 1.2–4.5 kHz 频段测存在感（ep28 高出前后 14～33 dB），全频 RMS 会被配乐重音淹掉。
