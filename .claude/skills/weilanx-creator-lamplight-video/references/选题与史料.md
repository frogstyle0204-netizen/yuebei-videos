# 选题与史料

## 什么样的题好

同时满足三条：

1. **一个人人听过、但理解错的说法或规矩**。标题是悬念问句，点出这个词、不说答案：「「八百里加急」到底有多快？」。开场第一句就把误会摆出来（「你以为……？」），第 7、8 拍把它打掉。
2. **能被画出来的模型**：路线（驿传、漕运、烽火）、城市（宵禁、坊市、消防）、档位（加急三档、刑罚等级）、数量（驿站数、人数、额度）、时间（更点、昼夜）。素材库里有现成的：地形图 + 发光路线、透视城市逐格亮灯、俯视坊块、纸卷律文、档位卡、人数卡、昼夜盘、十匹马。
3. **能查到原文的数字**：律文、正史、典制（六典、会典）、笔记（梦溪笔谈、东京梦华录）。没有原文撑的题先不做。

题的口子要小、具体（一条规矩、一种制度），不要「唐朝的交通」这种大题。一期讲一个题，按朝代推进 2～3 个时代，越往后越狠，最后给一个现代的落点（电报来了、这个词留下来了）。

> **2026-10-15 起主选题池在 `materials/08-灯火史话风/选题.md`**（按抖音数据排序，公式：现代日常 × 古代版本）；下面两批是旧池子，好的已经挑过去了。

## 怎么查原文

- **维基文库全文**：`curl -sL "https://zh.wikisource.org/wiki/<书名>/<卷>?action=raw" -o /tmp/x.txt`，再用 Python 按关键词取上下文（注意是繁体：「京師」「驛」）。ep28 的「幽州在京師東北二千五百二十里」就是这样从《舊唐書》卷 39 取到的。
- **识典古籍 / 5000yan / 古诗文网**：`curl` 下来去标签 grep，或 `mcp__web-reader__webReader` 读全文。
- **搜索**（WebSearch）只用来找「在哪本书哪一卷」，结论要回到原文确认。
- **学者文章**（澎湃、社科院历史所、期刊）：可以直接引用学者的结论（标「据某某」），但他转引的律文、数字最好再对原书。

记录方式：每个数字记「说法 | 出处（书名 + 卷 + 条目）| 核对情况（读到原文 / 转引 / 自己算的）」，写进文案稿的事实清单和 `timeline.ts` 的常量注释，测试里断言。

## 史料的坑（ep28 遇到的）

- **俗称 ≠ 规定**：「八百里加急」在会典里查不到，正式档位最高「六百里加紧」。片子只说「它变成了一句话」，不说「清朝规定八百里」。
- **版本数字不一致**：《唐六典》驿站数 1639（识典古籍）vs 1629（维基转述），而且水驿 + 陆驿 + 水陆兼驿加起来是 1643。取主流本，核对清单里注明。
- **原文没有的话别安进去**：常被引用的「自范阳至长安三千余里，师行六日」在《资治通鉴》原文里没有；距离改用《旧唐书·地理志》的 2520 里，天数用干支自己算。
- **「确认」和「听说」要分清**：玄宗之前已经听到传言，庚午是「上闻禄山定反」——叙述写「6 天后，玄宗确认了消息」，不写「消息 6 天传到」。
- **律文的递加要算对**：「一日杖八十，二日加一等」→ 晚两天杖九十；「罪止徒二年」是上限。
