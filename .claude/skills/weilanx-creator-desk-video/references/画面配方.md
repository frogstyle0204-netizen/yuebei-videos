# 画面配方

## 口播内容 → 组件

信息卡在 `src/library/warm-desk/props.tsx`，设计图形（主视觉）在 `motifs.tsx`，舞台元素在 `stage.tsx`。

| 口播在说什么 | 用什么 | 怎么挂 |
|---|---|---|
| 开场钩子、反差、结论金句 | `Headline`（粗黑体，`kicker` 小眉标，`〔词〕` 朱橙渐变块刷入 + 星光） | 逐字跟口播，`hiAt = cw(n, '关键词')` |
| 开场列本期卖点 / 几个关键词 | `Chips`（编号白卡依次弹起）+ `Badge`（旋转环字徽章：版本号、期数） | 卖点挂在标题后面 4 帧；徽章挂第一句 |
| 「做这件事分 N 步」 | `StepBar`（大卡片版，`y≈260`） | 卡片依次上浮；之后 `DeskShow` 顶部自动挂紧凑版 |
| 「第 N 步 / 第 N 个，XX」 | `ChapterTitle`（大号描边编号 + PART 0N 胶囊 + 大字 + 细线 + 进度点，`total` 总章数） | 单独一屏，停 1～2 秒；场景 `step: N−1`、`hop: true`；配 `ding` + 提前 4 帧轻 `whoosh` |
| 「你能带走什么」「答案有三个」 | `MysteryCards`（编号问号卡翻起） | 挂在「什么」上 |
| A 和 B 并列（理论 + 实践、输入 → 输出） | `IconCards`（图标大卡 + 中间 `+` / `→` 圆钮；图标 `LineIcon`：book / tool / code / film / bulb / user） | 每张挂各自的词，圆钮晚 6 帧 |
| 一份说明书 / 规则 / 清单 | `ListCard`（编号圆点逐行从左滑入，`hi` 行浅橙底 + 左侧橙条，`stack` 叠纸，`accent` 角标） | 每行 `at` 挂 `cw(n, '行里的词')`；讲到哪行 `hi` 跟到哪行 |
| 「视频就是一帧帧画面」这类原理 | `FilmStrip`（深色胶片条，小球一格格挪，缓慢上滚） | 放在清单卡右边当辅助元素 |
| 核心 → 外延（原理 → 方法 → 技巧） | `Rings`（三层同心圆，中心实心橙，外圈虚线描出、反向慢转，圈顶挂标签） | 三个 `at` 挂三个词 |
| 命令 / 安装 / 跑起来 | `CodeCard dark`（深色终端，逐字敲出，光标闪，敲完绿勾） | `per` ≈ 28 帧一行，每行配一声轻 `type` |
| 做出来了 / 这就是成片 | `PlayerCard`（迷你暖纸画面 + 播放钮 + 进度条在走） | 挂在「视频」「成片」上，背后 `Sparkle` |
| 一条流程（A → Skill → B） | `FlowCards`（STEP 卡 + 橙色虚线 + 跑动光点，最后一张橙色） | 每张挂一个词，最后一张迸星光 |
| 往期作品 / 案例 | 每期自己画的作品卡（缩略画面用各风格配色画极简示意 + 播放钮 + 片名 + 风格标签；样例：ep26 `WorkCards`） | 依次翻起，之后 `drift` 轻漂 |
| AI 来问你 / 你在做选择 | `OptionCard`（问题 + 编号选项，`pick` 选中） | `pickAt = cw(n, '选项词')` |
| 几个档位比较（快慢、浓淡、版本） | `SpeedCards` | 每张卡跟一句，最后一张打勾 |
| 逐字 / 逐帧 / 时间轴 | `CharTimeline` | |
| 一张表（分镜、计划、对照） | `TableCard`（`hiCol` 高亮某列） | 先出行，讲到那一列再 `hiColAt` |
| 一个口诀 / 缩写 / 几个维度 | `LetterCards` | 每个字母 `gap` 对应一句口播 |
| 你 vs AI / 两边轻重 | `Seesaw` | |
| 一堆截图 / 抽帧 / 版本 | `ThumbGrid`、`CardFan` | |
| 数量 | `BigCount` | 「八处问题」「52 周」 |
| 用户说的一句话 / 指令 / 某个 Skill 名 | `SayBubble`（橙色圆头像 + 白气泡） | 「我只说了一句：做一条……」 |
| 一个标签、状态 | `Tag`（橙色渐变胶囊 / 浅橙底朱字），可以套一层 `rotate(±3deg)` | 贴在卡片右上角当标注 |
| 声音、配音 | `Waveform` | |
| 结尾关注 | `FollowCard`（头像 + 我是 XX + 关注按钮变已关注 + 点赞 / 关注 / 收藏依次点亮） | 最后一个场景，吉祥物 `eyes: 'star'`、`hop` |
| 揭晓、重点 | `Sparkle` 星光迸发 | **放在内容后面**（DOM 里先画），半径要大到线条落在卡片外 |

示例文案里的数字要么是用户真实做过的，要么标「示意」；不编数据。

## 版式安全区（1920×1080）

| 区域 | 给谁 |
|---|---|
| y 34–94 | 顶部紧凑步骤条（`DeskShow` 自动画） |
| x > 1480、y > 640 | 右下角吉祥物（脚底约在 1640, 990；真人口播缩到 `{x: 1700, y: 1000, s: 0.75}`） |
| y > 950 | 底部字幕（48px 粗黑体，纸色描边托底，居中） |
| 主内容（配音口播） | x 200–1460、y 130–900；卡片宽 700–1000，标题 96–140 号，卡片正文 ≥ 30 号 |

### 真人口播：左下角出镜小窗

| | 小窗 | 主内容区 | 适合 |
|---|---|---|---|
| A-roll | `x 60`、边长 540，底边 y 920 | x 680–1460：粗黑体大标题（108 号）+ 一排辅助元素（`Chips`、`MysteryCards`、`FollowCard`、`Badge`） | 开场自我介绍、提问、结尾求关注——人在说重要的话 |
| B-roll | `x 46`、边长 330，底边 y 920 | x 440–1460、y 130–900：主视觉 | 讲内容、讲步骤 |

- 小窗用 `HostCam`（圆角 16，不要再大；白边 + 背后错开的朱橙卡 + 虚线框 + 白色名字胶囊），挂在 `DeskShowConfig.overlay` 上，这样不会随换场重播；`camAt(f)` 在每个场景开头 12 帧内从上一个姿态平滑过渡到这一个（ep26 现成）。
- 小窗大小切换跟着场景的 `roll` 走；章节卡一律 B-roll，`ChapterTitle` 给 `cx={1000}` 避开小窗。
- `decor` 的避让矩形：小窗区 `[0, 340, 640, 620]` + 主内容区 `[440, 120, 1040, 780]`，漂浮几何只出现在边上。

## 节奏

- **一句口播一个变化**：新卡片上浮、某一行高亮、橙块刷入、一圈同心圆点亮、步骤条前进一格。观众的眼睛永远有一个落点。
- **换场不硬切**：`DeskShow` 在下一个场景开始时让旧内容倾斜滑走并变模糊（`leave` 控方向，默认左右交替），新场景里的元素回弹上浮；场景内镜头缓推 2.5%（`push`）；同一个元素换位置用 `slide` 平滑挪。
- **章节标题单独一屏**：步骤开始时 `ChapterTitle`，配 `ding` + 吉祥物跳一下。
- 场景 `from = cf(n) − 6`（画面略早于口播）；挂在句尾词上的动画会来不及看，重点挂在句子前半。
- 口播里有长停顿（3 秒以上）时，用清单逐行出现 / 高亮移动把停顿填上（`ListCard` 的 `gap` 拉大）。

## 吉祥物（CC）

- 默认 `open`（会自己眨眼）；惊讶 / 发现问题用 `wide`，开心 / 搞定用 `happy`，结尾用 `star`；卡住了用 `flat` 或 `spiral`。
- 头顶小反应：`!`（发现 / 关键点）、`?`（疑问 / 卡住）、`note`（顺了 / 节奏）、`dots`（思考 / 等待），挂在口播对应的词上。
- 只用素材库的 `PixelBuddy`，不画参考视频里的像素橘子。

## 音效（共享 `public/audio/sfx/`）

| 时机 | 音效 | 音量 |
|---|---|---|
| 卡片落下 / 出现 | `paper` 或 `pop` | 0.22–0.26 |
| 步骤点亮、章节标题 | `ding` | 0.22–0.24 |
| 章节卡进场前 4 帧 | `whoosh` | 0.16 |
| 选中、打勾、高亮 | `click` | 0.24–0.26 |
| 代码 / 文字逐字出现 | `type`（每行一声） | 0.2–0.22 |
| 结论揭晓、橙块刷入 | `magic` | 0.2–0.22 |
| 换场滑走 | `whoosh` | 0.16–0.2 |

人声是主角，音效宁轻勿重；导出时 `export.sh` 会把音效轨再压 3 dB。

## 自查清单

1. 封面（第 0 帧）是 `DeskCoverWide`，第一句口播前淡出。
2. 顶部步骤条只在正文出现，当前步骤跟口播一致，做完的打勾。
3. 每个画面只有一种强调色（朱橙）；没有出现第二种强调色（作品缩略图里的示意配色除外）。
4. 每个场景都有一个主视觉 + 一个辅助元素，没有「一张卡 + 大片空白」；卡片和字够大（列表行 36px、标题 ≥ 92），没有压进吉祥物区、出镜小窗和字幕区。
5. 星光没有压在字上；`Sparkle` 在 DOM 里排在内容前面。
6. 每句口播都有画面变化；挂在 `cw` 上的动画在说到那个词时出现。
7. 吉祥物表情和小反应跟口播情绪对得上。
