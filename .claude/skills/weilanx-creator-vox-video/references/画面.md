## 骨架

```tsx
type Shot = {from: number; kind: 'A' | 'B'; C: React.FC<{f: number; s: number}>};

const SHOTS: Shot[] = [
  {from: 0, kind: 'B', C: sOpen},        // 实拍开场
  {from: cf(2), kind: 'A', C: aNumber},  // 钩子数字
  {from: cf(4), kind: 'B', C: sOpen},    // 切回实拍 + 「对吧？」
  // ……
];

export const Film: React.FC<{f: number}> = ({f}) => {
  // 找当前镜头；B 镜头包 BShot（桌面 + 整体慢推 5%），A 镜头直接渲染
};
```

- 一切挂在字幕上：切点用 `cf(n)`（可提前 2～6 帧），镜头内的元素用 `cf(n) + k` 或 `cw(n, '词')`。
- `Film` 里拿到的 `f` 是全局帧；视频 `VoxFootage` 的 `start` 必须等于这个镜头的 `from`（或想让视频开始的那一帧）。

## 什么时候用 A-roll 黑卡

口播里这几类句子切黑卡，一句一张：

| 句子类型 | 黑卡写法（ep21） |
|---|---|
| 钩子数字 | 「650 亿个」：Anton 330 号黄色数字往上滚 + 「穿过了你的小指甲盖」+ 红色下划线 |
| 名词揭晓 | 「2026 诺贝尔物理学奖」+ 奖牌贴纸；「幽灵粒子」+ 英文斜体；「冰立方 IceCube」 |
| 问句 | 「怎么抓一个幽灵？」大问号 |
| 反转 | 「听起来很疯狂？」→「他们真干了」（黄色大字） |
| 结论 | 三句逐句出现，前一句变暗，最后一句黄色大字 + 下划线 + 一个小图标 |

- 字体 `VF.heavy`，主字号 110～260，数字用 `VF.num`。
- 强调用**黄色字（`V.hiSolid`）+ `Underline` 红色手画线**；黑卡上不要用 `Highlight`（混合模式在黑底上看不见）。
- 下划线放在字的基线下方 20px 以上，抽帧确认没有压字。

## 什么时候用 B-roll

讲事实、讲过程、讲地点和人的时候。每个 B 镜头 = 1～2 个真实素材 + 2～4 个 Vox 批注：

| 镜头 | 素材 | 批注 |
|---|---|---|
| 开场 | NASA 动画：粒子流 → 地球被穿过 | 「就在这一秒」标签、红圈、手写「你毫无感觉，对吧？」 |
| 地点 | 南极实验室实拍 | 索引卡「南极点 · 冰立方实验室」、手写「有人抓住了它们」 |
| 是什么 | 诺奖官方插图 | 右侧三条打勾的特点 |
| 人物 | 获奖者照片 | 年份大字、名字、身份索引卡 |
| 过程 | 实拍 + 动画 + 官方结构图 | 盖章（又深 / 又透明）、闪光、大数字计数（86、5160） |
| 结果 | NASA 动画（星图、喷流） | 年份索引卡、红圈、「40 亿光年外」 |
| 道理 | 风景照 + 手画图解 | 分步出现的线、红叉、手写结论 |

- `VoxFootage` 尺寸常用 1000～1300 宽；画面左右留出 400～600 宽给批注；内容不要低于 y=900（下面是字幕条）。
- 照片推近 `zoom: [1, 1.1~1.15]`，`focus` 对准主体；官方插图用 `focus` 裁出最有用的那一块（例：结构图对准碰撞点）。
- 同一个镜头里先后出现的元素用 `At` 包住，按口播分步出现。
- 2～4 秒一个切点；不要连续 3 个以上同类镜头；同一段视频可以切回来再用一次（开场 → 黑卡 → 回到地球）。
