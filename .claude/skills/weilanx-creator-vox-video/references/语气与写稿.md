# 语气与写稿

目标：**听起来像一个很会讲故事的人在跟你聊天**，不是播音员在念稿。用户明确否掉过两种：播音腔、僵硬的「激情澎湃」。

## 结构（约 1 分钟，400～430 字）

```text
钩子（2 句：和观众本人有关的反差 + 「对吧？」）
→ 引出主角（1 句：今年的 XX，偏偏颁给了……）
→ 是什么（1～2 句 + 一个外号 / 比喻）
→ 怎么做到的（问句开场 → 想法 → 「听起来很疯狂，可他们真干了」→ 惊人的数字）
→ 结果（2 个里程碑，年份 + 一句话）
→ 为什么重要（「你想啊」开场，讲清和以前比多了什么）
→ 深度结尾（「所以这个 XX 的意义不只是……而是……」，最后一句短、能单独成立）
```

## 语气抓手（每 1～2 段放一个）

| 类型 | 例句（ep21） | 作用 |
|---|---|---|
| 把观众拉进现场 | 就在你听我说这句话的这一秒，已经有 650 亿个粒子，穿过了你的小指甲盖。 | 钩子：和「你」有关 |
| 反问确认 | 你一点感觉都没有，对吧？ | 制造共鸣和停顿 |
| 转折 | 可今年的诺贝尔物理学奖，偏偏颁给了一个抓住它们的人。 | 反差 |
| 问句开场 | 那怎么抓一个幽灵呢？ | 带出下一段，制造悬念 |
| 惊叹 + 反转 | 听起来很疯狂，可他们真干了。 | 让数字有分量 |
| 引导思考 | 你想啊，人类看宇宙，几百年来靠的几乎都是光…… | 从事实转到意义 |
| 深度结尾 | 所以这个诺奖奖励的不只是一台仪器，而是人类看宇宙，多了一双不靠光的眼睛。 | 余味，不升华成口号 |

## 写法

- 一个意思一句话，用逗号连，句子之间有「可、所以、那、于是、还」这类连接词。
- 每段至少一个具体数字或画面（650 亿、86 个深洞、5160 个探测器、40 亿光年），数字要能被画面接住。
- 外号比术语好记：先说术语，马上给外号（中微子 → 幽灵粒子；冰立方望远镜 → 一立方公里的冰）。
- 不说「OK，本期视频就到这里，我们下期再见」，也不求关注。
- 不用冒号、括号、破折号；数字用阿拉伯数字，约数用汉字（两千多米）。
- 绝对说法先查证：「第一次」「唯一」「最」不确定就改成「多了一双……」「找到了……」。

## 配音参数（`scripts/tts_expressive.py`）

- 语气提示（默认）：自然、松弛、像跟朋友聊天的科普博主；开头抓人带神秘感；问句带好奇和调侃；惊人处有惊叹；结尾放慢带感慨；不要播音腔、不要一字一顿、不要每句一个调。
- 语速：`--rate 30`（模型原生加速，比后期 `atempo` 自然）。425 字 → 约 61 秒。
- 想更燃：在提示里加「关键数字加重语气」；想更沉稳：`--rate 20` 并删 30～40 字。
- 用 `scripts/voice_stats.py` 比较版本：ep21 自然版 60.9 秒、音高范围 15.7 半音、停顿 43 次（平均 0.33 秒）；之前后期加速的「激情版」停顿只有 37 次（0.29 秒）。
