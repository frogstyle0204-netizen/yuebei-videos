# 素材：权威、真实、授权清楚

用户要求：**不要只用拼接贴纸，要用网上权威的图片和视频**。B-roll 的分量来自真实素材。

## 去哪找

| 来源 | 授权 | 适合 |
|---|---|---|
| NASA / NSF / NOAA 等美国政府机构 | 公有领域（注意个别第三方素材除外） | 太空、地球、科学动画 |
| Wikimedia Commons（`scripts/commons.py`） | CC0 / CC BY / CC BY-SA / 公有领域 | 实拍照片、人物、设备、结构图；Commons 上也有很多 NASA 视频（.webm，含 4K） |
| 官方新闻稿配图（nobelprize.org 等） | 常见「非商业免费使用，需署名」 | 原理插图（最权威、最好懂） |
| 机构官网图库 | 看各自条款 | 补充 |

不用：来路不明的图片、YouTube / B 站视频、新闻网站的版权照片、AI 生成的「示意真实照片」。

## 流程

1. `python3 scripts/commons.py search "关键词"`（加 `--video` 找视频），英文关键词效果更好。
2. `python3 scripts/commons.py info "File:..." ...`：看尺寸、时长、**授权**、**作者**（`Artist` 字段，是真正的作者；不要写成上传者的用户名）。
3. `python3 scripts/commons.py get "File:..." /tmp/<期>/raw/xxx.jpg` 下载原图（Commons 的原图可能上百 MB，下到 /tmp）。
4. 图片：`sips -s format jpeg -s formatOptions 85 -Z 1800 原图 --out public/footage/<期>/xxx.jpg`。
5. 视频：
   - 每 5 秒抽一帧拼联系表：`ffmpeg -i v.webm -vf "fps=1/5,scale=384:216" f%03d.jpg`，再 `tile` 拼图；
   - 选中的片段附近每秒抽一帧确认；
   - 剪成小段：`ffmpeg -ss <起> -t <长> -i v.webm -an -vf "scale=1280:720,fps=30" -c:v libx264 -crf 20 -preset medium -pix_fmt yuv420p -movflags +faststart public/footage/<期>/nasa-xxx.mp4`；
   - 片段长度要大于它在片子里出现的总时长（切回来再用的要算上）。
6. 官方网站的插图：用浏览器 UA 的 `curl` 下载，页面里 `Illustrations` 一节通常写着使用条款。
7. 写 `<素材目录>/素材来源.md`：文件、内容、作者、来源、授权；再列事实出处链接。

## 画面上的署名

- 每个 `VoxFootage` 传 `credit`：`照片：作者 / CC BY 4.0`、`视频：NASA Goddard（公有领域）`、`插图：© 作者 / 机构`。
- 动画类素材（黑洞、粒子）在批注里写「动画示意」。
- 发布文案末尾写一句素材来源和授权。
- 用了「非商业」素材的，汇报时提醒用户：带商业推广的话要换掉。
