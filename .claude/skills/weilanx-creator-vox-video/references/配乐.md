# 配乐与节奏感

参考代码：`audio/episodes/ep21-nobel-physics.mjs`。乐器和出片工具在 `audio/score.mjs`（`pad`、`pulse`、`bell`、`bass`、`kick`、`snap`、`hat`、`boom`、`crash`、`swell`、`fall`、`wind`、`grid`、`loadCues`、`writeScore`）。只跑 `node audio/episodes/<期>.mjs`。

## 骨架

```js
const BEAT = 60 / 124;          // 124 BPM
const BAR = BEAT * 4;
const T0 = 0.2;
const snapBar = (t) => T0 + Math.round((t - T0) / BAR) * BAR;   // 段落切换吸到最近的小节线

const SEC = [[0, 'intro'], [snapBar(cs(2)), 'hook'], ……];        // 段落表，跟着口播结构
const PROG = {hook: [Am, F, C, G], ghost: [Em, Em, Dm, Em], ……};  // 每段和弦进行
const energy = {intro: 0.3, hook: 0.65, drop: 1, breath: 0.35, ……}[sec];
```

逐小节渲染：铺底（`pad`，亮度随 energy）→ 十六分方波琶音（`pulse`）→ 八分音符贝斯 → 鼓。

## 让它「有节奏、有动感」的五件事

1. **节拍不断**：一条 124 BPM 网格从头走到尾，四拍底鼓 + 二四拍军鼓；energy ≥ 0.8 的段落踩镲改十六分。
2. **侧链式呼吸**：渲染完后把旋律总线乘一个包络，每拍底鼓落下时压下去再放开（`1 - depth * exp(-phase * 9)`，depth 0.55）。这是电子乐「一顿一顿往前走」的感觉来源。
3. **剪辑咬着音乐**：每次切到黑卡前 0.9 秒推一段 `swell`，切点上落一下 `boom`（低频，不和音效的高频打架）。
4. **3～4 个高潮点**：揭晓（蓝光）、名字（冰立方）、震撼数字（40 亿光年）、结论（最后一句）各配 `crash + boom`，前面用 `swell` 推上去。
5. **有呼吸的结构**：
   - 解释概念的段落转半速（底鼓只在每小节第一拍，琶音八分）；
   - 结尾前的转折句（「你想啊」）律动全部收掉，只留铺底和稀疏琶音，侧链压浅；
   - 下一句（「中微子不会」）重新起拍，一路推到最后一句落重击；
   - 最后铺一个大调和弦加一串铃音，余韵铺满后淡出。

## 音量

- `writeScore({ep, render, segs, level = 0.071, depth = 0.7})`：整轨 RMS 定到 0.071，有人声时压 70%，整轨约 −32～−34 LUFS（人声 −16 LUFS）。
- `segs` 填段落表，脚本会打印每段闪避前后的响度：留白段应该最静，高潮段最响。
- 用户说律动不够明显时，可以把鼓总线系数（`wd * 0.7`）调大，或 `level` 提到 0.085，先问用户。
- 配乐长度跟 voice.wav 走：voice.wav 要先 `apad` 到 `VOICE_SECONDS`，余韵才有音乐。
