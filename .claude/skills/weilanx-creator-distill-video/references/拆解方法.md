# 拆解方法：从参考视频里读出画面语法

机器报告给的是数字，真正的风格要靠人眼看出来。下面是暗金文献风那次拆解里用过、有效的做法。

## 先看结构，再看细节

1. **节奏骨架**：报告的镜头表 + 运动强度曲线。
   - 硬切很少、镜头很长（暗金原片 130 秒只有 7～8 个硬切）→ 这是「同一画面里元素进出」的风格，要学的是元素的入场退场，不是剪辑。
   - 硬切很多、镜头 1～2 秒 → 剪辑风格（Vox 拼贴），要学的是切点和每个镜头的构图。
   - 运动强度长时间很低、偶尔尖峰 → 安静画面 + 少数爆点，尖峰处就是它的招牌时刻。
2. **画面分类**：通看联系表，把画面归成几类，每类找 2～3 个代表帧。暗金原片分出来是：标题卡、年份抬头 + 文献引用的固定版式、对决数字、实物（骰子、金币、羊皮纸）、金线图表、引文、结尾卡。每一类就是素材包里的一个或一组组件。
3. **固定版式**：哪些元素在大多数画面里都在同一个位置（左上年份、右上文献、底部字幕、右下水印）？这是风格的「框」，要做成组件；水印位置记下来但不复制内容。

## 看细节的手法

- **局部放大**：`ffmpeg -ss 31 -i 原片 -frames:v 1 -vf "crop=900:300:0:0" 局部.png`，看字体是衬线还是无衬线、笔画粗细、字距、描边、阴影、渐变方向。
- **取色**：`uv run --with pillow python -c "from PIL import Image; im=Image.open('帧.png').convert('RGB'); print(im.getpixel((x,y)))"`。底色在四角和中心各取一次（判断有没有光晕和暗角），文字和线条取最亮处。
- **质感**：放大看平坦区域有没有颗粒噪点、纸纹、浮尘光点；有就做成独立的叠加层组件。
- **字体**：先判断气质（宋 / 黑 / 楷、Garamond / Didot / 无衬线），再在仓库已有字体和系统字体里找最接近的；找不到合适的、又必须新加时，只用 OFL 等允许再分发的字体。

## 动效：用切片数帧

`strip.py` 在一个时间窗里等间隔取帧拼成一条，每格标「秒 + 相对帧号」。

- **入场**：在元素出现前 0.2 秒开始、窗口 1 秒、8 帧。看它是透明度渐显、带模糊、从下往上、从大到小还是逐字出现；数到完全出现用了几帧（暗金：约 18 帧，模糊 + 透明一起收）。
- **退场**：同样切一条，看是和入场对称还是更快。
- **转场**：在两个画面交界处切 1.5 秒。是硬切、交叉淡化、闪白 / 黑场、还是同一个元素变形贯穿？
- **镜头运动**：长镜头里隔 2 秒取一帧，看有没有缓慢推近 / 平移（暗金：每场推近约 2～3%）。
- **缓动**：位移类动画在窗口里取 10 帧，量元素位置随帧的变化——前几帧走得多后几帧走得少是 ease-out，两头慢中间快是 ease-in-out，有回弹就是 back / elastic。
- **招牌时刻**：运动强度的尖峰、音乐重拍附近，单独切细一点（`--span 0.6 --n 12`）。

## 音频

报告里的卡点结果用来回答：画面节点是不是卡在小节线上？高潮是不是踩在「换气 + 重拍」上？这决定素材包要不要提供「按小节排时间」的工具。配乐本身不进素材包。

## 多支视频

各自拆完后列一张对照表：每一项（底色、主色、字体、版式、入场、转场、节奏）写各支的做法。全部一致的进「画面特征」，不一致的做成组件参数（`tone: 'warm' | 'cool'`）或在配方卡里写成「变体」。

## 记下来

拆解过程中的观察直接写进配方卡草稿（`references/配方卡模板.md` 的结构），每条尽量带数字：颜色值、字号、帧数、百分比。没有数字的「感觉」很难变成代码。
