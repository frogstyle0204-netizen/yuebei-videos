# 风格配方卡模板

写进 `styles/我的风格/<中文名>/README.md`。参考已有的 `styles/我的风格/暗金文献风/README.md`。每条尽量带数字（颜色值、字号、帧数、百分比）。

```markdown
# <中文名>

![预览](预览.jpg)

<一句话定位：适合讲什么内容、像什么>。画面语法是从参考视频里拆出来的（<视频文件名>，不进 git），组件和示例都是重写的，没有沿用原片的内容、文案和水印。

## 画面特征

- **底色与质感**：<底色值、光晕位置和颜色、暗角、颗粒 / 纸纹 / 浮尘>
- **配色**：<只用哪几类颜色，各自用在哪里；强调色的使用规则（比如一个画面最多一处）>
- **字体**：<数字 / 西文 / 中文各用什么，字重，字距>
- **固定版式**：<哪些元素固定在哪个位置>
- **出场方式**：<透明 / 模糊 / 位移 / 缩放 / 逐字，几帧完成，缓动>
- **转场**：<硬切 / 交叉淡化 / 元素贯穿 / 闪白，频率>
- **镜头**：<推近 / 平移 / 静止，幅度和速度>
- **节奏**：<平均镜头长度、硬切频率、是否卡音乐>
- **招牌画面**：<最能代表这个风格的 2～3 个画面或动作>

## 组件

| 文件 | 组件 |
|---|---|
| `src/library/<风格ID>/theme.ts` | … |
| `src/library/<风格ID>/stage.tsx` | … |
| `src/library/<风格ID>/props.tsx` | … |
| `src/library/<风格ID>/charts.tsx` | … |

## 关键代码

- 素材库：`src/library/<风格ID>/`（目录见 `src/library/README.md`「<中文名>」一节）
- 预览：Studio 里的 `library-<风格ID>`（`src/library/previews/<Name>Demo.tsx`）

## 没有搬的东西

- <原片的文案 / 标题 / 水印 / 人物 / logo / 配乐，各自怎么处理的>

## 期数

还没有正式使用的期数。
```
