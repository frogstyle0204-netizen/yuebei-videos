# 3：共同语法

四个「3：」风格（享乐主义、尼采与权力意志、悲观主义、虚无主义）的共同底子。

**一句话：这四支参考视频是同一个栏目。** 每期讲一个哲学「主义」，用同一首配乐、同一个叙事模板、同一套字体和版式，只换「皮肤」（主色、隐喻物、场景）。所以「月背来信」的视频 skill = 一套固定底子 + 每期选一种皮肤。

四支原片用同一套脚本重新测过（原片、截图和测量包都在 `materials/` 和 `template/`，不进 git）。下面的数字都是实测。

## 测量对象

| 风格 | 代码 ID | 时长 | 硬切 | 平均镜头 | 平均亮度 | 暗部占比 | 饱和度 | 响度 | 音效 |
|---|---|---|---|---|---|---|---|---|---|
| 3：享乐主义 | `vessel-stage` | 168.8 秒 | 7 | 21.1 秒 | 0.117 | 72% | 0.39 | −17.2 LUFS | 少量 |

## 一、四支共用的东西（固定底子）

### 1. 音乐：四支是同一首曲子

- 四支的配乐是**同一首录音**：逐段比对波形，相关系数 0.68–1.0（两首不同的曲子会接近 0）。悲观主义和虚无主义里只有这首曲子，另外两支在上面叠了少量音效。
- **速度 112.91 BPM**，一拍 0.531 秒（15.9 帧），一小节 2.126 秒（63.8 帧），第一拍在 0.110 秒；整首速度不漂。
- **结构**（小节 k 从 0.110 + 2.1256 × k 秒开始）：

  | 段落 | 小节 | 时间 | 响度 |
  |---|---|---|---|
  | 前奏，安静 | 0–7 | 0–17.1 秒 | 约 −21 dB |
  | **第一重拍** → 主段 | 8–35 | 17.1–76.6 秒 | −19 ～ −16 dB |
  | 回落，安静 | 36–43 | 76.6–93.6 秒 | −24 ～ −22 dB |
  | **第二重拍** → 尾段 | 44 起 | 93.6–126 秒 | 约 −19 dB |
  | 曲子结束 | | 约 126 秒 | |

  两个重拍都比前面突然响 7 dB 以上，分别在第 513 帧和第 2809 帧。网格数据在同目录的 `music-grid.json`。
- **用法**：四支都在第 0 帧直接起音乐，不淡入；片尾直接切断，不淡出。长于 126 秒的两支把曲子从头又接了一遍。
- **音色**：低频很重（60 Hz 以下占 67–74% 的能量），频谱重心 170–250 Hz，每秒约 2.9 个起音。是一首暗、厚、鼓点轻的电子氛围曲。
- **换场和字幕不卡拍**：硬切和字幕出现的时间落在拍点 ±0.1 秒内的比例是 21–67%，随机也有 38%；落在小节线上的比例是 0–22%，随机是 9%。剪辑跟阅读速度走，音乐只是铺底，**只有两个重拍和叙事结构对上**（见下一节）。
- **两张配方卡写错了**，以这里为准：享乐主义卡写的「约 128 BPM、字幕卡小节线、锚词踩重拍」，尼采卡写的「约 90 BPM 钢琴」，实际都是这首 112.9 BPM、不卡拍的曲子。

### 2. 叙事模板（时间点跟着这首曲子走）

| # | 段 | 时间 | 做什么 | 四支怎么做的（概括） |
|---|---|---|---|---|
| 1 | 钩子 | 0 – 约 6 秒 | 用「你是否……？」问一个熟悉的生活瞬间，1–3 句 | 跑步跑到第二圈想停下；聚会散场后的空荡；摆烂过后；为什么上班 |
| 2 | 认领 | 约 5–9 秒 | 把观众的感受认领成这个主义：「如果是，那……就是 X」，主义名用大字砸出来 | 尼采 8.2 秒出「权力意志」，虚无 7.6 秒出「虚无主义」 |
| 3 | 收进角标 | 约 9–17 秒 | 大标题缩成左上角的主题签；这一段是全片最暗的 | 四支在 12–17 秒之间左上角都已有主题签 |
| 4 | **第一重拍** | **17.1 秒** | 进入「概念世界」：核心隐喻物或场景在这里建立（前后 1 秒内），常带上哲学家的名字 | 一桌金杯 + 伊壁鸠鲁；俯视跑道 + 起点光环；叔本华剪影；星轮下的地平线 |
| 5 | 误解 → 正解 | 17 – 约 40 秒 | 先说大家以为的，再翻过来 | 享乐不是大吃大喝；推倒神坛不是为了躺平；热闹只是一层滤镜；最难熬的不是起点和终点 |
| 6 | 原话 + 隐喻展开 | 约 40–76 秒 | 「X 说……」+ 一个隐喻物贯穿到底，中间砸 1–3 个锚词大字 | 杯子；跑道、绳索、桥；吊灯 = 钟摆；地平线 |
| 7 | 回落 | 76.6–93.6 秒 | 音乐变安静，叙事拐向答案 | 三种欲望；「叔本华给了两个出口」；骆驼变狮子 |
| 8 | **第二重拍** | **93.6 秒前后** | 转折或核心金句 | 一项 1978 年的研究；「人这一生终究只能独自面对自己」；「狮子只会摧毁，无法建立」（87 秒那支在这之前就结束了） |
| 9 | 落点 + 结尾 | 最后 10–20 秒 | 把道理落回观众的生活，最后一屏是一个问题，或者回到开头的画面闭环 | 「你此刻缺的，究竟是更多还是更少？」；「然后呢」；散场后的空就是自由；开头的杯口 / 小人回来 |

第 2 步原片三支都用了同一句口头禅，那是原作者的个人标记，属于内容。我们只学「认领」这个结构，句子自己写。

### 3. 画面底子

- **近黑底 + 一个主色系 + 暖白字**。平均亮度 0.11（黑白那支 0.06），68–92% 的画面是暗部。
- **明暗分三段**（四支都一样）：
  - 0–8 秒的钩子是全片最亮、颜色最多的部分（生活场景），亮度是正文的 1.1–1.7 倍，运动是正文的 1.1–2.9 倍；
  - 8–17 秒的标题段最暗，亮度只有正文的 0.46–0.89；
  - 17 秒后的正文暗而静。
- **几乎不动**：一半的时间运动强度低于 0.004。镜头基本不动，动的是画面里的元素（光点、小人、被画出来的线）。
- **硬切很少**：每分钟 2.5–5 刀，平均一个镜头 11–21 秒。换场靠溶解、元素贯穿（上一场的线、杯口、光变成下一场的东西）、闪白，硬切大多藏在闪光里。
- **人物**：无脸的剪影、火柴人或线描小人，常带一个发光点（心口的光、身上的光团）。
- **一期一个核心隐喻物**，从第一重拍一直用到结尾，结尾回到它。

### 4. 文字

- 中文全部宋体。无口播，字幕就是旁白。
- 字幕一句停 2.5–3 秒，每屏 1–3 行，一行 20 字以内。重点词加粗，再加本期主色。
- **锚词**：宋体最粗的大字，居中，逐字从模糊里收拢；每期 2–5 个（减法、需要更少；权力意志、超越；想要、痛苦、无聊、孤独、庸俗、自由；虚无主义、体面、顺从、然后呢）。
- 入场一律是「透明 + 模糊」一起收拢，退场模糊淡出。
- **角落**：左上主题签（主义名 + 一行西文或作者小字）；右上一个细线框的小账号框（原片是作者水印，我们写自己的账号名）；引用出处用西文斜体小字。

### 5. 声音

- 无口播，配乐全程不闪避。
- 音效可有可无：两支一个音效都没有，另两支有少量很轻的高频闪光声和低频轰鸣。

## 二、每支不一样的部分（皮肤）

| 皮肤 | 主色（含义） | 场景底 | 核心隐喻物 | 人物 | 字幕位置 | 素材包 |
|---|---|---|---|---|---|---|
| 3：享乐主义 | 金（欲望、更多）+ 陶土（朴素、够用） | 暗场舞台、黄昏龟裂地、夜海 | 杯子 | 剪影 | 顶部居中 | `src/library/vessel-stage/` |
| 3：尼采与权力意志 | 赤红 + 米白 + 影子红（退缩的声音） | 透视 / 侧视 / 俯视跑道 | 跑道、绳索、桥 | 发光火柴人 + 红色影子 | 上方或人物对角 | `src/library/crimson-glow/` |
| 3：悲观主义 | 冷蓝（独处）+ 琥珀（热闹、回忆） | 深夜房间 | 吊灯 = 钟摆 | 心口发光的剪影 | 底部 | `src/library/nocturne/` |
| 3：虚无主义 | 黑白星点线描，中段一次白纸反转 | 夜空、地平线 | 地平线、星轮 | 线描小人 | 底部 | `src/library/constellation/` |

做新一期：讲的主义和四个之一气质接近就直接用那套皮肤；不接近就按同样的规则配一套新皮肤（一个主色系 + 一个隐喻物 + 一种人物画法），其余全部照固定底子。

## 三、skill 的验收标准（「像」的定义）

成片用同一套脚本测一遍，下面每一项都落在范围里才算合格，再和原片并排看一遍联系表。

| 项 | 合格范围 |
|---|---|
| 画幅 | 1920×1080，30 fps |
| 平均亮度 | 0.10–0.12（黑白皮肤 0.05–0.07） |
| 暗部占比 | ≥ 68% |
| 钩子段（0–8 秒）亮度 ÷ 正文亮度 | 1.1–1.8 |
| 标题段（8–17 秒） | 全片最暗 |
| 运动强度中位数 | ≤ 0.004 |
| 硬切 | 每分钟 2.5–5 刀 |
| 字幕 | 一句停 2.5–3 秒，每行 ≤ 20 字 |
| 第一重拍 17.1 秒 | 核心场景已经建立，主题签已经在左上 |
| 第二重拍 93.6 秒（片长超过它时） | 转折或核心金句 |
| 音乐 | 第 0 帧起，不淡入不淡出；整片 −17 ～ −20 LUFS |
| 结尾 | 一个问题，或者回到开头的画面 |

## 四、待你定的三件事

1. **音乐从哪来。** 四支用的是同一首曲子，所以音乐最像的办法是用同一首。原曲不能从视频里扒出来用。可以在抖音原视频页面左下角看曲名：如果是抖音曲库里能用的曲子，发布时在抖音里配上同款、从开头起，画面按上面的网格做就能对上。不行的话，另找一首有授权的同类曲子（暗、低频重、约 110–115 BPM、前面 8 小节安静然后进重拍），skill 自动测拍子，把两个重拍换成新曲子的位置。
2. **时长。** 原片是 87–169 秒，之前那几篇文章建议 1 分钟以内。要像原片，我建议按原片做，默认 120 秒左右，在曲子 126 秒循环之前结束。
3. **认领那句话。** 原作者的口头禅不用，我们每期自己写；也可以定一句月背来信自己的固定句式。

## 测量方法

- 剪辑、镜头、主色：`weilanx-creator-distill-video/scripts/analyze.py`
- 明暗、运动、字幕出现时间：逐帧脚本（10 fps 测明暗和运动，30 fps 测文字出现）
- 音乐：同一首曲子用波形互相关对齐；在只有音乐的那两支上拟合拍子网格（100–125 BPM 之间每 0.01 BPM 试一次，拍点上起音强度最大的就是；再分 8 秒一段检查，每段都对得上，说明速度不漂）；每拍、每小节测响度找段落和重拍
- 音效：从各支的音频里减掉对齐后的曲子，剩下的就是叠上去的音效

这些脚本做 skill 时会放进 skill 目录，验收时用同一套。
